# RALEN-WEB

Shopify theme for RALEN.

## Phase 1

- Dark minimal visual system
- Configurable Shopify header
- Split-text intro powered by GSAP
- Session-aware skip/show behavior
- Trend-ready hero with editable image, product, copy, CTA and badge
- Responsive layout and reduced-motion support

The hero is intentionally data-driven so its featured image/product can later be updated by a trend-selection system without redesigning the page.
